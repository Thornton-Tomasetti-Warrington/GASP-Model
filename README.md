A Python script which allows the user to setup and solve the 6 coupled ODEs of the GASP model (Webber, 1990). This models the extent and rate of liquid spills on a flat, level surface, in addition to the liquid temperature and liquid evaporation rate.

This was initially coded using Python in Google Colab Notebook, hence the .ipynb file. For ease of access, the code has been provided as a .py file too. 

The model is set up for a water spill for a specific spill case, so properties should be changed for spills of other liquids in different scenarios.
